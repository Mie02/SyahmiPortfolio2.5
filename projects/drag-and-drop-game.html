Drag & Drop Learning Game

A Unity-based interactive learning game focused on drag-and-drop matching with feedback. Designed for clarity, smooth UI flow, and replayability.

Unity C# UI/UX Game Logic Audio

How it works

Step 1 — Drag & Drop

Players drag answer tokens into matching slots. System tracks when all slots are filled.

Step 2 — Validation

Submit button validates each slot and provides correct/wrong feedback instantly.

Step 3 — Scoring & Timer

Points and countdown timer create replayability; difficulty adjusts background and UI.
